# LOCAL

## External Name: Local Docker Compose Repositiory

## Get Started

1. Download docker daemon. [For Mac](https://docs.docker.com/desktop/install/mac-install/)
2. Create a [personal access token](https://docs.github.com/en/enterprise-server@3.6/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)
3. `docker login ghcr.io -u USERNAME -p <put your token here>`
4. `docker compose pull`
5. `docker compose up -d`
